# NeverDestruct documentation

Write online in **https://app.pagescms.org/**. Select this repository, then **Documentation**.

- Add and reorder Chapters in the editor.
- Within each chapter, add formatted text, pictures or playable videos in any order.
- Heading 2 and Heading 3 within formatted text appear as subchapters in the left outline.
- Pictures enlarge when clicked; MP4/WebM videos play in the page.
- Reading layout chooses continuous reading or one chapter at a time.
- Appearance controls width and colours.
- Save in Pages CMS to update GitHub. GitHub Pages then publishes the update.

GitHub Pages setup: **Settings -> Pages -> Deploy from a branch -> main -> /docs -> Save**.

The configuration is `.pages.yml` at the repository root. All website files are in `docs/`.
